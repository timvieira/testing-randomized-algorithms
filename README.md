# Ideas for Testing Randomized Algorithms

Blog post exploring practical techniques for testing randomized algorithms: checking distributional correctness, using program tracing, and verifying Monte Carlo estimators.

**[Read the post](https://timvieira.github.io/testing-randomized-algorithms/)**

## Development

Requires the [blog build system](https://github.com/timvieira/blog):

```bash
blog dev      # build + watch + serve locally
blog deploy   # build + commit + push to GitHub Pages
```
